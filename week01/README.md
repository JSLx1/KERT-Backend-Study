# KERT 웹 백엔드 스터디 - 1주차
백엔드 스터디 1주차: express 사용

## 실행 방법
1. `node.js`, `npm`이 설치되어 있는지 확인합니다.
2. clone한 디렉토리에서 `npm install`을 실행, 의존성 패키지를 다운로드합니다.
3. clone한 디렉토리에서 `node app.js`를 실행합니다. 
4. `localhost:3000`에 서버가 열렸습니다!
 
## 구현한 라우트
- `/about`: 제 이름을 간단하게 소개합니다.
- `/time`: 현재 시간을 보여줍니다.
- `/photo`: 호반우(`hobanwoo.png`) 사진을 보여줍니다.

 
## 연습 문제
`10 / 10 통과`
 
## (도전) /time 이 새로고침할 때마다 바뀌는 이유
- 사용자가 서버에 HTTP/GET 요청을 보낼 때마다 새롭게 값을 구하기 때문입니다.
- 새로고침할 경우 서버에 요청을 보내는 시간이 달라지므로, 당연히 서버가 구해서 사용자에게 보여주는 시간 값도 달라집니다.
